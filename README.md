## Research

**Automated Detection of Nocturnal Blue Tears Using YOLO12n and CutMix Data Augmentation**
S. Nazeer, A. Qadeer, R. Saleem, S. Asghar, **F. Hassan\*** (corresponding author)
*Journal of Magnetism and Its Applications*, 2026 · [DOI: 10.5281/zenodo.24392762](https://doi.org/10.5281/zenodo.24392762)

Detecting faint, transient blue bioluminescence in night-time coastal images with a one-class YOLO12n detector.

| Metric | Result |
|---|---|
| mAP@50 | 95.09% |
| mAP@50-95 | 72.03% |
| Precision / Recall | 92.45% / 89.89% |
| F1-score | 91.15% |
| Gain from CutMix (mAP@50) | +7.86 points |
| Model size | 2.56M parameters |

Evaluated on BT3.8k: 3,827 annotated images from 241 user-uploaded videos.
